# cyber-labs

      Laboratório prático em ambiente isolado e controlado, no qual uma máquina Kali Linux (atacante) realiza testes de segurança contra uma máquina Metasploitable (alvo propositalmente vulnerável). O objetivo é praticar, na ordem em que acontecem num teste de intrusão real, as fases de reconhecimento, enumeração e exploração de serviços vulneráveis. Também documento a mitigação de cada falha e os rastros que o ataque deixa nos logs, para entender o cenário tanto pela ótica do atacante quanto pela do defensor.
